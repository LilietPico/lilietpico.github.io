Robot Lili Pico — source code (for YouTube API Services review)

Strictly internal tool with a single user: the owner of the YouTube channel Lili & Pico. It runs on GitHub Actions in a private repository. No credentials are included here: OAuth client credentials are stored in encrypted GitHub secrets and the refresh token is stored encrypted.

  • robot/envoyer.py — complete upload script: resumable videos.insert (private, scheduled publishAt, made for kids), then captions.insert and thumbnails.set. Disabled until the audit is approved.
  • robot/programmer.py — daily scheduler: finds the owner's private uploads, applies metadata, localizations, captions and thumbnail, then schedules publishing at midnight (Montreal time).
  • robot/fiches.py — reads the episode metadata files (titles, descriptions, tags, captions, thumbnails).
  • robot/jeton.py — OAuth 2.0 token handling (encrypted refresh token, access token refresh).
  • workflows/programmer.yml — GitHub Actions workflow.

Endpoints used: videos.insert, videos.list, videos.update, captions.list, captions.insert, captions.update, thumbnails.set, channels.list, playlistItems.list.
