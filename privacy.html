Privacy Policy — Robot Lili Pico

Last updated: November 15, 2026. Version française

1. Who we are

"Robot Lili Pico" is a strictly internal, private tool operated by the owner of the YouTube channel Lili & Pico (Quebec, Canada). It has a single user: the channel owner. It is not offered to the public.

2. Use of YouTube API Services

This tool uses YouTube API Services. By using it, the user agrees to be bound by the YouTube Terms of Service. Data obtained from Google is also governed by the Google Privacy Policy.

3. Information accessed and used

With the channel owner's authorization (OAuth 2.0), the tool accesses only the Lili & Pico channel in order to:

  • upload the channel's videos and set their details (title, description, tags, language, "made for kids" audience, publish date);
  • add translated titles and descriptions, captions and thumbnails;
  • read the list and status of the channel's videos to check these settings.

The tool does not collect any data about viewers, children, subscribers or any other person. It does not read comments, measure audiences, or combine API data with any other data.

4. Storage and security

The only data kept is the channel's authorization token. It is encrypted and stored in a private code repository, and its decryption key is kept in encrypted secrets. No other information is stored.

5. Sharing

No information is sold, rented or shared with third parties. Data is used only to manage the Lili & Pico channel.

6. Revocation and deletion

Authorization can be revoked at any time at myaccount.google.com/permissions or from the Google security settings page. After revocation, the encrypted token is deleted within 7 days. Deletion requests can also be sent to the address below.
